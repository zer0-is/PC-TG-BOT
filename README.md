# PC Bot

Telegram-бот и графическая панель для управления **собственным компьютером**.
Панель запускается в Windows, работает в системном трее и хранит настройки
в отдельном `.env` рядом с приложением.

> Используйте программу только на компьютерах, которыми вы владеете или
> которые уполномочены администрировать. Скриншоты, снимки с камеры и данные
> буфера обмена по запросу отправляются в Telegram.

## Возможности

- Панель Windows: запуск, остановка и перезапуск бота, просмотр логов,
  настройка автозагрузки и редактирование API-параметров.
- Меню Telegram для просмотра состояния и процессов ПК, открытия приложений,
  управления мультимедиа и настройками питания.
- Запрос снимка экрана или камеры, работа с буфером обмена и приём отправленных
  файлов в папку «Загрузки».
- Необязательная команда `/ask` через OpenRouter.

## Быстрый запуск

### Готовый EXE

1. Скачайте [PCBot.exe](releases/PCBot.exe) или соберите его из исходников.
2. Запустите приложение. При первом запуске откройте вкладку **API / .ENV**.
3. Укажите токен своего Telegram-бота и свой числовой Telegram ID, сохраните
   настройки и нажмите **Запустить**.
4. Откройте чат с ботом и отправьте `/start`.

Файл `.env` создаётся рядом с EXE. Он не вшит в приложение и не должен
публиковаться или пересылаться. Python для запуска готовой сборки не требуется.

### Из исходников

Требуются Windows 10/11 и Python 3.13.

1. Склонируйте репозиторий или скачайте исходники.
2. Запустите `setup.bat`. Он создаст `.venv` (если его ещё нет), установит
   зависимости и откроет графическую панель.
3. В панели заполните вкладку **API / .ENV**, сохраните настройки и запустите
   бота.

Для консольного запуска после настройки можно использовать `start_bot.bat`.

## Настройка

Создайте бота через [@BotFather](https://t.me/BotFather) и укажите только свой
Telegram ID в списке разрешённых пользователей. Панель создаёт `.env`
автоматически. Для ручной настройки можно скопировать `.env.example` в `.env`
и заполнить значения:

| Переменная | Обязательная | Назначение |
|---|---:|---|
| `BOT_TOKEN` | Да | Токен вашего Telegram-бота |
| `ALLOWED_USER_IDS` | Да | Разрешённые числовые Telegram ID, через запятую |
| `OPENROUTER_API_KEY` | Нет | Ключ для команды `/ask` |
| `OPENROUTER_MODEL` | Нет | Модель OpenRouter; по умолчанию `inclusionai/ling-3.2-flash:free` |
| `POWER_DELAY` | Нет | Задержка перед действием питания, в секундах |
| `ALLOW_SHELL` | Нет | Выполнение команд оболочки; выключено по умолчанию |
| `ALLOW_FILES` | Нет | Отправка файлов с ПК через бота; выключено по умолчанию |

Оставляйте `ALLOW_SHELL` и `ALLOW_FILES` выключенными, если вы полностью не
понимаете последствия. Не используйте бота для доступа к чужим устройствам.
Если ключ Telegram или OpenRouter попал в открытый доступ, немедленно отзовите
и замените его.

## Сборка EXE

После запуска `setup.bat` выполните `build_exe.bat`. Скрипт установит PyInstaller
и соберёт однофайловое приложение `releases\PCBot.exe`. Сборка не включает
`.env`, токены или логи.

## Панель и логи

- Кнопка закрытия окна скрывает панель в трей; бот продолжает работать.
- Для полного выхода выберите **Выход** в меню значка панели. Если бот запущен,
  приложение предложит остановить его.
- Логи сохраняются в `logs\bot.log` рядом с приложением. Не добавляйте логи
  в публичный репозиторий: они могут содержать идентификаторы пользователей.
- Автозагрузку панели можно включить или отключить кнопкой в главном окне.

## Структура проекта

```text
bot.py             Telegram-бот
control_panel.py   Графическая панель Windows
requirements.txt   Python-зависимости
setup.bat          Подготовка окружения и запуск панели
build_exe.bat      Сборка Windows EXE
releases/          Готовая сборка для Windows
.env.example       Шаблон без секретов
```

`.env`, виртуальное окружение, логи и временные файлы исключены через
`.gitignore`. В репозитории нет файла лицензии; права на повторное
использование кода отдельно не предоставлены.
